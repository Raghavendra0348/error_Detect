# ✨ Bit Code Converter Suite

🔗 **Live Demo**: [https://bit-code-converter.vercel.app](https://bit-code-converter.vercel.app)

Bit Code Converter Suite is an all-in-one online tool for encoding Hamming codes, detecting errors, converting number systems, and transforming Gray codes. It's designed especially for students and professionals in computer science, electronics, and digital systems.

---

## 🚀 Features

- ✅ **Hamming Code Encoder** – Generate Hamming codes with even/odd parity
- 🛑 **Error Detection** – Detect and locate single-bit errors in Hamming code
- 🔢 **Number System Converter** – Convert between Binary, Decimal, Octal, and Hexadecimal
- 🌀 **Gray Code Converter** – Binary ↔ Gray and Gray ↔ Binary
- 🔐 **Authentication System** – Signup/Login to access explanation sections
- 📱 **Responsive Design** – Mobile and desktop friendly with a collapsible menu
- 📃 **Informational Pages** – About, Contact, Privacy Policy, Terms of Use
- 🔄 **Smooth Navigation** – No page reloads between tools

## 📦 Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/bit-code-converter.git
   cd bit-code-converter
   ```

2. **Run locally**:
   - Open `index.html` in your browser
   - Or use Live Server extension in VS Code

3. **Deploy**:
   - Recommended: [Vercel](https://vercel.com) (1-click deployment)
   - Or use GitHub Pages for static hosting
